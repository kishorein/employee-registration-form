# Employee Registration Form

A simple employee registration form built with HTML, CSS and JavaScript, with client-side form validation. No frameworks, no build tools, no installation needed.

## Features

- Employee registration form
- Form validation with JavaScript before submission
- Lightweight and fast: plain HTML, CSS and JS only
- Runs in any modern browser

## Tech Stack

- **HTML5** for the form structure
- **CSS3** for styling
- **JavaScript (Vanilla)** for validation and form logic

## Project Structure

```
employee-registration-form/
├── index.html   # Form markup
├── style.css    # Styles
└── main.js      # Form validation logic
```

## Getting Started

1. Clone the repository

   ```bash
   git clone https://github.com/kishorein/employee-registration-form.git
   ```

2. Go into the project folder

   ```bash
   cd employee-registration-form
   ```

3. Open `index.html` in your browser (double-click the file, or use the Live Server extension in VS Code).

## Usage

1. Open the form in your browser.
2. Fill in the employee details.
3. Click the submit button. If any field is missing or invalid, an error is shown and the form is not submitted.
